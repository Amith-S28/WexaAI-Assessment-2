# Goal-Driven Autonomous Execution

Operate autonomously to achieve complex development goals without requiring continuous micro-prompting.

## Core Execution Loop

1. **State Explicit Milestones**: Break the overarching objective into distinct, verifiable checkpoints:
   - Checkpoint 1: [Target Deliverable] -> Verification criteria
   - Checkpoint 2: [Target Deliverable] -> Verification criteria
   - Checkpoint 3: [Target Deliverable] -> Verification criteria

2. **Iterate with Test-Driven Gates**:
   - Write or execute verification scripts/tests at each step.
   - Loop and self-correct on any errors before proceeding to the next checkpoint.

3. **Verify Against Definition of Done**:
   - Security boundaries respected.
   - Resource limits verified (< 512MB RAM).
   - Zero silent failures.
   - Comprehensive error logging and live diagnostics.
